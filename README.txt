Nova ClassTint Compat Pack v1
============================

These textures are exported as *minimal uncompressed* TGA Type-2 (32-bit BGRA)
with bottom-left origin. This is intended for strict texture loaders that
return 0x0 dimensions for more complex PNG/TGA variants.

Use .tga URLs in your loader (it already tries TGA first).
Render with WHITE tint (pre-tinted textures).
